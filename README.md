# H5P Single Choice Set (CFRD)

Fork CFRD de **Single Choice Set** (upstream 1.11, `coreApi` 1.28).

- `machineName`: `H5P.SingleChoiceSetCFRD`
- Constructor JS: `H5P.SingleChoiceSetCFRD`
- Editor: `semantics.json` + widgets en `editorDependencies` (sin `H5PEditor.SingleChoiceSet`)

## Desarrollo

```powershell
npm run sync:h5p-cli
```

Copia la librería a `h5p-cli/libraries/H5P.SingleChoiceSetCFRD-1.0/` para probar con `h5p server`.
